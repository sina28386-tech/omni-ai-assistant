# دستیار هوشمند Omni

[English](README.md)

اُمنی یک پروژهٔ آزمایشی دستیار هوشمند برای ویندوز و اندروید است. هدف آن کنار هم گذاشتن سرویس‌های مدل، گفتگو و ابزارهای محلی در یک محیط با رابط فارسی و انگلیسی است. پشتیبانی از قابلیت‌ها به مدل، سرویس‌دهنده، مجوزهای دستگاه و برنامهٔ هدف بستگی دارد.

## بخش‌های پروژه

- `desktop`: رابط React و سرویس محلی Node.js برای گفتگو، ارائه‌دهنده‌ها، فضای کار، بات و ابزارهای ویندوز.
- `windows-shell`: پوستهٔ Electron و تنظیمات ساخت نصب‌کنندهٔ ویندوز.
- `android`: برنامهٔ Kotlin و Jetpack Compose برای اندروید، شامل ابزارهای دستگاه، پروفایل مدل و ورودی صوتی.

## اجرا و ساخت

برای اجرای دسکتاپ، Node.js و npm را نصب کنید و از ریشهٔ پروژه این دستورها را اجرا کنید:

```powershell
cd desktop
npm ci
npm run build
npm start
```

سپس `http://127.0.0.1:4317` را باز و سرویس دلخواهتان را در برنامه تنظیم کنید. برای ساخت نصب‌کنندهٔ ویندوز، بعد از ساخت دسکتاپ وارد پوشهٔ `windows-shell` شوید و `npm install` و سپس `powershell -ExecutionPolicy Bypass -File build.ps1` را اجرا کنید.

برای اندروید، JDK 17 و Android SDK 36 لازم‌اند. پس از تنظیم مسیر SDK در Android Studio یا فایل محلی `android/local.properties`، از پوشهٔ `android` دستور `./gradlew :app:assembleDebug` را اجرا کنید. فایل حاصل یک نسخهٔ توسعه‌ای است و انتشار رسمی و امضاشده محسوب نمی‌شود.

## وضعیت و محدودیت‌ها

مدل باید از فراخوانی ابزار پشتیبانی کند تا بتواند از ابزارهای گوشی استفاده کند؛ روشن‌بودن گزینهٔ ابزار به‌تنهایی اثبات پشتیبانی مدل نیست. برخی عملیات به مجوز دستگاه و تأیید کاربر نیاز دارند و همهٔ برنامه‌ها کنترل‌های قابل‌دسترسی ارائه نمی‌کنند.

تایپ صوتی فارسی و انگلیسی از سرویس گفتار نصب‌شده روی گوشی استفاده می‌کند؛ کیفیت، سرعت و امکان نمایش متن زنده به سرویس و دستگاه بستگی دارد. ابزار موسیقی فایل‌های محلی گوشی را جست‌وجو و پخش می‌کند. پخش از سرویس‌های آنلاین با این ابزار تضمین نشده است.

نسخهٔ ویندوز در صورت نصب و ورود قبلی می‌تواند از Codex CLI محلی استفاده کند. ورود مستقیم به حساب Codex در اندروید هنوز پیاده‌سازی نشده است. کلیدهای API نسخهٔ ویندوز فعلاً در فایل محلی `secrets.json` و بدون استفاده از مخزن امن رمز سیستم‌عامل ذخیره می‌شوند. دادهٔ لازم برای پاسخ به سرویس مدل انتخاب‌شده ارسال می‌شود.

پل اختیاری رایانه در `android/scripts/hermes_pc_agent.py` قرار دارد و از سرویس دسکتاپ ویندوز جداست. این پل از توکن و فهرست محدودی از عملیات استفاده می‌کند و به‌طور پیش‌فرض فقط روی همان رایانه گوش می‌دهد. خود پل TLS ندارد؛ برای اتصال شبکه‌ای از ارتباط رمزگذاری‌شده استفاده کنید. این پل ورود Codex به اندروید را فراهم نمی‌کند.
