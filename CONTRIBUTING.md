# Contributing

Thank you for helping improve Omni. Before starting a large change, open an issue describing the problem and your proposed approach. For a pull request:

1. Keep the change focused and describe the user-visible behavior.
2. Run the relevant tests and include the commands and results in the pull request.
3. Do not include API keys, device databases, private conversations, signing keys, emulator data, or local configuration.
4. Preserve third-party license notices and clearly identify any new third-party assets or code.
5. Do not claim that a device action or provider integration works without a test that demonstrates it.

For potential vulnerabilities, follow [SECURITY.md](SECURITY.md).
